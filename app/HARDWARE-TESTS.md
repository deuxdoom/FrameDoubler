# 하드웨어 검증 절차와 상태

지원 목표와 실제 확인을 구분합니다. 2026-11-14 현재 보유 장비는 Windows 11 x64,
i7-14700KF와 RTX 4080 SUPER 16GB 한 대입니다.

| 구성 | 실제 상태 |
|---|---|
| NVIDIA GPU + Intel CPU | Vulkan 4.25/4.26, FP32/FP16 저장, CPU 대체, NVENC 및 소프트웨어 인코더 확인 |
| 같은 기준 PC의 선택형 RTX | C API 네이티브 엔진·실제 설치 자체 검사·두 모델/두 scale/세 시간값·홀수 RGB 행·취소·ncnn 대체·sample 2 전체 출력 확인. 다른 장비는 미검증 |
| NVIDIA GPU + AMD CPU | 장비 없음, 미검증 |
| AMD Radeon GPU | 장비 없음, 미검증. AMF 목록은 현재 PC에서 실행 불가 |
| Intel Arc / Intel 내장 GPU | 장비 없음, 미검증. QSV 목록은 현재 PC에서 실행 불가 |
| 실제 복수 GPU | 장비 없음, 미검증. 선택 정책만 가짜 목록으로 단위 검증 |
| 실제 Vulkan 미지원 PC | 장비 없음, 미검증. 기준 PC에서 Vulkan 비활성 강제 경로/명시적 CPU 실행만 검사 |

실행 확인이 모든 영상의 품질을 보증하지는 않습니다. 두 모델의 FP16 중간 텐서 저장에서 확인한
수치 기준 미달을 보완하기 위해 제품은 FP32 저장·연산을 사용합니다. sample 2 전 구간에서 고른
실제 프레임 쌍과 두 모델 전체 변환, 비정렬 RGB8/RGB16·CPU/GPU 경로를 추가 검증했습니다.

CUDA·DirectML·PyTorch CUDA는 같은 PC에서 개발 비교만 했으며 제품 백엔드가 아닙니다.
선택형 RTX는 `accel status`와 실제 설치 자체 검사를 확인한 뒤 `--accelerator rtx`·`auto`·`vulkan`을
비교합니다. RGB16·수동 CPU·가속 파일 오류 때 대체 경로와 처리 기록도 확인합니다.
복수 동일 GPU의 장치 대응과 실제 저메모리 장치는 검증하지 않았습니다.

각 장비에서는 다음을 실행하고 OS/CPU/GPU/드라이버, 결과 JSON과 오류 원문을 보관합니다.

1. `FrameDoubler.Cli hardware`: 장치 목록/유형/메모리/기능, 작은 실제 추론, 인코더별 8/10비트 시험.
2. 두 모델·1080p/1440p/4K에서 `--device gpu:INDEX`로 변환·verify. 자동 선택 결과도 기록.
3. 다른 GPU를 선택하여 실패 시 조용히 GPU 0으로 바뀌지 않는지 확인. GPU/인코더는 별개 장치일 수 있음.
4. `--device cpu --software`로 짧은 같은 입력을 변환. CPU 성능 안내와 실제 선택 경로 확인.
5. `FRAMEDOUBLER_DISABLE_VULKAN=1`에서 자동 대체 검사. 이는 실제 없는 드라이버/장치 시험을 대신하지 않음.
6. H.264/HEVC/AV1, 8/10비트, NVENC/AMF/QSV/소프트웨어를 **실제 성공하는 조합만** 확인.
7. 같은 원시 RGB 결과의 PSNR/MAE/p99/최대 차이, 출력 fps/길이/잔여 중복/오디오/색상 확인.
8. 실제 처리 시간과 OS private bytes/working set, GPU 메모리 예산의 전후/장시간 변화를 기록.
9. 취소·잘못된 장치·미지원 코덱·메모리 부족·드라이버 오류에서 메시지, 프로세스/임시 출력 정리 확인.

모델명이나 제조사명만으로 성공을 선언하지 않습니다. 보고하지 못한 메모리 값은 미확인입니다.
현재 메모리 선택은 보수적 추정과 실제 예산을 사용하며, 검증되지 않은 타일 처리는 적용하지 않습니다.
공통 경로는 CPU RGB 파이프를 사용합니다. 외부 GPU 디코딩/인코딩과 Vulkan 간 zero-copy는 미구현이며
복사 비용과 별도 인코딩 장치 간 비용은 후속 측정 대상입니다. 복수 실행 가능 GPU가 있으면 첫 보간 시 현재 해상도·비트 심도·모델로 예열 후 RGB 왕복/전송/추론 시간을 비교해 자동 선택합니다. 이 분기는 실제 복수 GPU 장비에서 아직 검증하지 않았습니다.
